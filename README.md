# Portfolio

My personal portfolio website: a single page with my experience, skills, education and contact details.

It's plain HTML and CSS with no build step or framework, so it's quick to load and easy to change.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8765
```

Then visit http://localhost:8765.

## Hosting

The site is hosted on [Render](https://render.com) as a static site. The settings are in `render.yaml`.
